Anti-gravity for Obsidian

The Anti-Gravity style, rebuilt as an Obsidian theme. Wide display headings, chamfered plates, hazard-edged alerts, corner brackets and one highlight colour. Void for dark mode, Bone for light. Your notes will look like they were issued by a mildly hostile orbital authority.

One zip, one folder, no account, no plugin required. Fonts are embedded, and the theme never makes a network request.

01 Install

Five steps. The only way to get it wrong is step three, so read step three.

01

Download the zip

Use the button above. Save it somewhere you can find it again, which is a higher bar than it sounds.

02

Open your vault's themes folder

In Obsidian, open Settings → Appearance. Next to Themes, click the folder icon. Obsidian opens <your vault>/.obsidian/themes/ for you, and creates it if it doesn't exist yet.

The .obsidian folder is hidden on macOS and Linux, which is why the button is the easy route. Doing it by hand: Cmd Shift . shows hidden files in Finder, Ctrl H in most Linux file managers.

03

Extract it into that folder

The zip contains a single folder called Anti-Gravity. It must end up directly inside themes, like this:

<your vault>/
└─ .obsidian/
   └─ themes/
      └─ Anti-Gravity/
         ├─ manifest.json   ← required
         ├─ theme.css       ← required
         ├─ OFL.txt         font licence
         └─ README.md       reference
The double-folder trap Windows "Extract All" and some macOS tools wrap everything in an extra folder named after the zip, giving you themes/Anti-Gravity-obsidian/Anti-Gravity/. Obsidian will not look inside it. Move the inner Anti-Gravity folder up one level and delete the empty wrapper. 
# Linux / macOS, from inside the themes folder
unzip ~/Downloads/Anti-Gravity-obsidian.zip
04

Reload Obsidian

Newer versions of Obsidian don't always show a refresh button next to Themes. Reload instead:

  • Desktop: open the command palette (Ctrl P, or Cmd P on macOS) and run Reload app without saving. Quitting and reopening also works.
  • Mobile: close the app fully from your recent apps, then open it again.
05

Select the theme

Settings → Appearance → Themes, choose Anti-Gravity. Light and dark follow Obsidian's own Base color scheme setting on the same page.

"This theme didn't provide a readme" Expected, and harmless. Obsidian only fetches readmes from its online theme directory, never from your local folder. The README is in the theme folder if you want it.

02 Configure

Optional. The defaults are fine. The options are there for people who disagree.

06

Install Style Settings

Settings → Community plugins. If restricted mode is on, turn it off. Click Browse, search for Style Settings, install it, then enable it. Its options appear under Settings → Style Settings → Anti-Gravity.

Classic calloutsOffPlain bracket bar instead of the hazard edge, with Obsidian's icons.

08

Phones and other devices

The theme lives inside the vault, so it travels with it.

  • Obsidian Sync: turn on Themes and snippets under Settings → Sync on each device.
  • Syncthing, iCloud, Git or similar: make sure the .obsidian folder is included. Many setups skip dot-folders by default.
  • No sync: copy the Anti-Gravity folder into .obsidian/themes/ on the device. You'll need a file manager that shows hidden folders.

Then select the theme on each device. Theme choice is stored per device.

03 Use

Most of the theme works on plain Markdown. Three extras need callout syntax.

04 PDF export

Obsidian exports every PDF in light mode, whatever you're looking at. The theme overrides that and exports in Void.

Set Margin to None In the Export to PDF dialog, set Margin to None. The theme adds its own padding to every page. Any other margin setting leaves a white border around each page.

Printing on actual paper? Turn on Light PDF export in Style Settings, unless you enjoy buying black ink.

05 Update

Manually installed themes don't update themselves. Check back here for new versions.

01

Replace the files

Download the new zip and extract it over the existing themes/Anti-Gravity folder, overwriting everything. Strictly, replacing theme.css and manifest.json is enough.

02

Reload

Run Reload app without saving, or switch to another theme and back. Your Style Settings choices are kept.

06 Troubleshooting

Things that go wrong, and why they're usually the folder.

SymptomFix
Anti-Gravity isn't in the theme listCheck the path is exactly .obsidian/themes/Anti-Gravity/theme.css, with no extra folder in between. Then reload Obsidian.
Installed it, but on the wrong vaultEach vault has its own .obsidian folder. Use the folder icon in Settings from inside the vault you want.
Missing on phone after syncingYour sync is probably skipping .obsidian, or Sync's Themes and snippets is off. Then select the theme on that device.
Highlight colour won't changeA CSS snippet setting --ag-accent-* overrides Style Settings. Disable the snippet, or edit it.
Some characters look differentThe embedded fonts cover Latin and Western European text plus common symbols. Other scripts fall back to your system font.
PDF has a white borderSet Margin to None in the export dialog.
Privacy

The theme is a single CSS file. No scripts, no tracking, no remote fonts and no network requests of any kind. The fonts (Michroma, Chakra Petch and Share Tech Mono) are embedded and licensed under the SIL Open Font License 1.1; the licence is in OFL.txt.

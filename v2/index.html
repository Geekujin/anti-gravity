2.4

16 Oct 2026 Current
New

.ag-card--link makes a whole card clickable from a single link. Put the link on the title only; it stretches over the card, so screen readers hear one link named by the title. The card takes a highlight border on hover and an inset focus ring.

<article class="ag-card ag-story ag-card--link">
  <div class="ag-story__num">01</div>
  <div class="ag-story__body">
    <span class="ag-tag ag-tag--text">Guide</span>
    <h3 class="ag-story__title"><a href="/guide/">Title</a></h3>
  </div>
</article>

2.3

16 Oct 2026
New

Prose placement: .ag-prose--center and .ag-prose--right move the reading column; .ag-prose--left is the default and can be set explicitly.

<article class="ag-prose ag-prose--center">…</article>
New

.ag-prose--full drops the 70-character measure and fills the available width with a 16px gutter each side. On an .ag-plate the plate keeps its own padding.

New

Variables --ag-prose-width (the measure, default 70ch) and --ag-prose-gutter (the full-width gutter, default 16px).

2.2

16 Oct 2026
New

.ag-linkline: a discreet text nav for under a site header. Links are separated by //; the current page sits on a highlight block. Rows wrap cleanly on narrow screens.

<nav aria-label="Main">
  <ul class="ag-linkline">
    <li><a href="/" aria-current="page">Home</a></li>
    <li><a href="/projects/">Projects</a></li>
  </ul>
</nav>
New

.ag-linkline--text: the same nav with the current page in highlight-coloured text and a chevron instead of a block.

2.1

16 Oct 2026
Changed

Toned tags and alert titles add their status glyph automatically (✓ ok, ! warn, ✕ danger, i info), so status never relies on colour alone.

Check your markup: if you typed a glyph into a toned tag or an alert title yourself, remove it or it will show twice.

Changed

The info tone is now neutral grey (#C9C7C3 on Void, #3A3A40 on Bone) instead of cyan, so it can never be confused with a highlight. Info fills on Bone take Bone text.

Changed

Danger status lamps always blink, with or without --pulse. They stop under reduced motion like everything else.

Changed

Signal's deep shade for small text on Bone moved from #E50014 to #E0102A, keeping it at 4.5:1 while staying closer to the main red.

New

Variables --ag-info-fill, --ag-info-on, --ag-on-tone and --ag-tone-glyph for building your own toned components.

2.0

6 Oct 2026

The first public release under the Anti-Gravity name. If you used a pre-release copy (anti-corpo.css or rogue-signal.css), these changes break your markup; see the migration table below.

Breaking

Class prefix is now ag- (was ac- or rs-), and the body class is class="ag".

Breaking

The file is anti-gravity.css, served from https://style.rogues.nexus/v2/.

Breaking

A custom highlight takes three variables: one for Void, one for Bone fills and large text (3:1 or more), and one for small text on Bone (4.5:1 or more).

:root {
  --ag-accent-dark:  #7CFF4F;
  --ag-accent-light: #4EA132;
  --ag-accent-deep:  #3E7F27;
}
New

Six highlights through data-accent: signal (default), neon, jensen, 2077, hack and gibson. Each has a shade tuned for Bone; 2077 is yellow on Void and turns grey on Bone.

New

Code and terminal: .ag-codeblock, styled plain pre, highlight.js and Prism colours, .ag-prompt, .ag-cursor and .ag-log.

New

Forms: every native control styled with no classes, plus .ag-field, .ag-input-group, square checkboxes, diamond radios, slanted switches and .ag-range.

New

Navigation: .ag-nav with slant and --notch variants, .ag-tabs, .ag-crumbs, .ag-pager, .ag-dropdown, .ag-menu and .ag-list.

New

Inverse kana: .ag-kana--inverse sets the word on a highlight block in the page colour; add .ag-kana--ink for ink-coloured text.

New

Load marker: the file ends with --ag-loaded: 1, so a page can detect a cut-off or mangled download. The file is plain ASCII, so it survives any re-encoding.

getComputedStyle(document.documentElement).getPropertyValue('--ag-loaded').trim() === '1'
